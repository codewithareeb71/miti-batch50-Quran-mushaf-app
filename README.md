# 🕌 Al-Quran Explorer – Premium Streamlit App

A modern and elegant **Quran Explorer** built with **Python** and **Streamlit**. This application provides a beautiful user interface to read the Holy Quran with multiple translations, audio recitation, and a premium reading experience.

---

## ✨ Features

* 📖 Browse all 114 Surahs
* 🌍 Multiple Translation Languages

  * English
  * Urdu
  * French
  * Persian
  * Russian
  * Chinese
  * Arabic Only
* 🎧 Audio Recitation
* 📜 Uthmani Arabic Script
* 🎨 Premium Modern UI
* ⚡ Fast Data Loading with Streamlit Cache
* 📱 Responsive Layout
* 🌙 Beautiful Islamic Theme
* 🔊 Verse-by-Verse Audio Playback

---

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/codewithareeb71/miti-batch50-Quran-mushaf-app.git
```

### 2. Go to Project Folder

```bash
cd miti-batch50-Quran-mushaf-app
```

### 3. Create Virtual Environment (Optional)

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**Mac/Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the App

```bash
streamlit run main.py
```

The application will automatically open in your browser.
